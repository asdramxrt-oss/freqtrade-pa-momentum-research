## 1. Objective

One question: **does the exact frozen EXP-003 long-only pullback-continuation
strategy generalise to genuinely unseen data, without any modification?**

This is a validation/replication experiment only. It is not optimisation,
improvement, feature engineering, ML research, combination research, or a
parameter search.

## 2. Hypothesis under test

> The long-only pullback-continuation edge observed in EXP-003 (full sample PF
> 1.567, 2025 OOS +14.01%) is a property of the setup and not of the 2019–2025
> sample, so it will remain net-positive and profitable on a fresh, contiguous,
> never-evaluated period.

Falsifiable: the fresh period is net-negative, or profit factor is below 1.00,
or the effect is absent.

## 8. Decision criteria (pre-registered, not changed after results)

Charter A1–A8 applied to the fresh window. Because the fresh window *is* the
holdout, the "full-sample" and "OOS" rows of A2–A5 coincide.

| # | Criterion | Threshold |
|---|-----------|-----------|
| A1 | Trades | >= 200 |
| A2 | Profit factor | >= 1.10 |
| A3 | Per-trade expectancy p-value | < 0.05 |
| A4 | Net return | >= 0 |
| A5 | Profit factor | >= 1.00 |
| A6 | Wallet max drawdown | < 35% |
| A7 | Profitable calendar years | >= 60% (single year 2026: 100% or 0%) |
| A8 | Profit factor @ 0.20% | **NOT EVALUATED** — the mission forbids a fee sweep; recorded as N/A rather than silently dropped |

**Pre-registered decision rule.**

- **FAILS FRESH OOS** if the fresh window is decisively negative: **net return
  < 0 (A4)** or **profit factor < 1.00 (A5)**. These are frozen thresholds and do
  not depend on the 200-trade bar.
- **SURVIVES FRESH OOS** only if **A1 passes** (>= 200 trades) **and** A2, A3,
  A4, A5, A6 and A7 all pass. (A8 is N/A.)
- **INCONCLUSIVE / REQUIRES FURTHER VALIDATION** otherwise — i.e. the result is
  not decisively negative but the sample is too small to satisfy the frozen
  criteria.

Known in advance: at the observed EXP-003 rate (~7 long trades/month) the
~8.5-month window is expected to yield well under 200 trades, so A1 (and
therefore a full PASS) is **probably unreachable by data availability alone**.
That is stated here before the run so that "INCONCLUSIVE by sample size" is not a
post-hoc excuse.

## 9. Statistical method

- Per-trade significance: freqtrade's `p_value` = **two-sided one-sample t-test**
  (`scipy.stats.ttest_1samp`) of per-trade returns (`profit_abs /
  starting_balance`) against a mean of 0. Reported with the sample size.
- Profit factor = gross profit / |gross loss|, from closed trades.
- Wallet drawdown = `wallet_stats.max_relative_drawdown` (the value freqtrade
  prints as "Max % of account underwater (balance)").
- No multiple-comparison adjustment is applied (a single pre-registered test);
  this is a stated limitation.
- If the trade count is small (< 30), the t-test is reported but explicitly
  flagged as under-powered rather than "significant".

## 11. Limitations

1. The window is short (~8.5 months) and will likely under-power A1 and the
   per-trade test; the verdict may be INCONCLUSIVE by construction.
2. Futures mode is used to match the EXP-003 long variant; funding is excluded.
3. Only one direction is tested by design; the short and combined variants are
   out of scope.
4. 2026 contains a single calendar year, so A7 is coarse.
5. A single OOS evaluation is performed; it must not be re-used for selection.
