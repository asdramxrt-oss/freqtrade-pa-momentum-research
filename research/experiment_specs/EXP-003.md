## 1. Objective

One question: **does a controlled counter-trend pullback followed by price-action
continuation confirmation capture a directional opportunity that survives the same
validation framework as the Turtle baseline?**

This is a standalone test. It is not a Turtle filter, not a Turtle combination,
and it is not permitted to use Turtle signals in any way.

## 2. Hypothesis under test

> After an impulse move establishes direction, a pullback that stays within
> predefined structural and volatility limits, and that then resumes in the
> original direction, provides a valid continuation entry.

Full statement: `research/hypotheses/pullback_continuation.md`.

The hypothesis is falsifiable: if the structure is not predictive, the profit
factor will sit at or below 1.0 and the per-trade expectancy will not be
distinguishable from zero.

## 3. Long / short scope (pre-registered)

`research/hypotheses/pullback_continuation.md` §6 inherited "long only" from the
Turtle risk section. EXP-003 **supersedes** that carry-over for this experiment:
the continuation geometry is direction-symmetric and the authorisation for
EXP-003 explicitly requires long, short and combined evaluation. Therefore, before
any run, EXP-003 pre-registers:

- **long-only** results,
- **short-only** results,
- **combined** results,

with the **combined** strategy as the primary object for criteria A1–A8. Both
sides use identical mirror-symmetric rules. A side may not be disabled or
redefined after seeing results.

## 4. Exact machine-readable rules

All rules are evaluated on closed 4h candles. A signal computed at bar `t` uses
only bars `<= t` and executes at the open of bar `t + 1` (freqtrade's default
execution model).

### 4.0 Causal structural primitives

- **Confirmed swing high** `SH(i)`: bar `i` is a swing high if
  `high[i] == max(high[i - L : i + R + 1])` with `L = R = 2`, and it is **published
  (known) only at bar `i + R`**. No bar before `i + R` may reference it.
- **Confirmed swing low** `SL(i)`: symmetric with `low` and `min`.
- **Last known swing high / low** at bar `t`: the most recent published value at or
  before `t` (forward-fill of the published series).
- **Origin low of the current impulse** `O_low`: the last-known swing **low** at
  the bar where the current last-known swing high was published.
- **Origin high of the current impulse** `O_high`: the last-known swing **high** at
  the bar where the current last-known swing low was published.
- **Bars since** a published event: number of bars elapsed since the most recent
  publication bar.

### 4.1 Long rules

| Step | Exact rule |
|------|-----------|
| A. Trend/impulse | There is a confirmed `SL`, then a later confirmed `SH`, with `SH > O_low` and `impulse_atr = (SH - O_low) / ATR_at_SH >= 3.0` |
| B. Impulse recency | `1 <= bars_since(SH) <= 10` |
| C. Pullback depth | `depth_atr = (SH - close[t]) / ATR[t]` is in `[0.5, 2.0]` |
| D. Structure holds | every `low` from the `SH` publication bar through `t` is `> O_low`, i.e. `min(low)[pub(SH) .. t] > O_low` |
| E. Continuation confirmation | `close[t] > max(high[t - 3 : t])` **and** `close[t] > open[t]` |
| F. Entry timing | `enter_long = rising_edge(A ∧ B ∧ C ∧ D ∧ E)`; fill at open of `t + 1` |

`ATR_at_SH` is the ATR(20) value at the `SH` publication bar (causal).

### 4.2 Short rules (exact mirror)

| Step | Exact rule |
|------|-----------|
| A. Trend/impulse | confirmed `SH`, then a later confirmed `SL`, with `SL < O_high` and `(O_high - SL) / ATR_at_SL >= 3.0` |
| B. Impulse recency | `1 <= bars_since(SL) <= 10` |
| C. Pullback depth | `(close[t] - SL) / ATR[t]` in `[0.5, 2.0]` |
| D. Structure holds | `max(high)[pub(SL) .. t] < O_high` |
| E. Continuation confirmation | `close[t] < min(low[t - 3 : t])` **and** `close[t] < open[t]` |
| F. Entry timing | `enter_short = rising_edge(A ∧ B ∧ C ∧ D ∧ E)`; fill at open of `t + 1` |

### 4.3 Stop, exit, sizing

| Element | Rule (identical to Turtle so the comparison isolates the entry) |
|---------|----------------------------------------------------------------|
| Stop | fixed `2 × ATR(20 at entry)` from the fill price; long below entry, short above entry |
| Backstop | `-30%` adverse (used only if the ATR lookup fails) |
| Exit | channel exit: long `close < min(low[t-10 : t])`; short `close > max(high[t-10 : t])` |
| ROI | disabled |
| Sizing | `equity × 0.01 / stop_distance × price`, capped at equity |
| Pyramiding | disabled (`position_adjustment_enable = False`) |
| Max open trades | 5 |
| Leverage | 1.0 |

## 5. Fixed parameters

`swing_left=2`, `swing_right=2`, `atr_period=20`, `impulse_min_atr=3.0`,
`pullback_min_atr=0.5`, `pullback_max_atr=2.0`, `max_pullback_bars=10`,
`confirm_bars=3`, `exit_period=10`, `atr_stop_multiple=2.0`, `risk_per_trade=0.01`,
`timeframe="4h"`.

These are hand-chosen round values fixed **before** the run for structural
reasons, not selected from a search. **None may be tuned in EXP-003.** No
hyperparameter search is performed.

## 6. Dataset

Identical underlying candles and universe to EXP-001/EXP-002 (Binance, 4h, 10
USDT pairs, 2019-01-01 → 2026-01-01, OOS 2025). No re-download.

**Unavoidable difference (documented, pre-registered):** freqtrade cannot express
shorts in spot mode, and the `binance` exchange supports only spot and futures
(margin is not available). Short and combined runs therefore use `trading_mode =
futures`, `margin_mode = isolated`, leverage 1.0, on a **futures mirror of the
exact same spot candles** (`user_data/scripts/prepare_futures_data.py` copies each
`binance/<PAIR>-4h.feather` to `binance/futures/<BASE>_<QUOTE>_<QUOTE>-4h-futures.feather`,
byte-identical OHLCV). No funding-rate data is present, so funding is excluded
from all results. A **spot long-only control** (`EXP-003-spot-long.json`) is run
on the original spot data so the mode deviation can be quantified: if the spot and
futures long-only results agree, the futures constraint is immaterial for longs.

## 7. Runs to perform

Frozen before execution. 30 futures runs + 3 spot control runs + 1 Turtle
reference run.

| Group | Mode | Directions | Timerange | Fee |
|-------|------|-----------|-----------|-----|
| Full sample | futures | long, short, combined | `20190101-20260101` | 0.05%, 0.20% (6 runs) |
| OOS holdout | futures | long, short, combined | `20250101-20260101` | 0.05% (3 runs) |
| Per year | futures | long, short, combined | `YYYY0101-YYYY+10101`, 2019…2025 | 0.05% (21 runs) |
| Spot control | spot | long | full + OOS | 0.05% (2 runs) |
| Turtle reference | spot | long | full | 0.05% (1 run, for complementarity only) |

**OOS accounting.** The pullback strategy is a new strategy version, so the 2025
holdout is its first and only selection-relevant evaluation. It is evaluated once
per direction variant. No parameter, threshold or decision is chosen from it.

## 8. Success criteria

Charter A1–A8, evaluated on the **combined** strategy, and tabulated for
long-only and short-only as well. Plus three pre-registered experiment-integrity
criteria.

| # | Criterion | Threshold |
|---|-----------|-----------|
| A1 | Trades (combined, full sample, base) | >= 200 |
| A2 | Profit factor, combined, full sample, 0.05% | >= 1.10 |
| A3 | Per-trade expectancy p-value, combined, 0.05% | < 0.05 |
| A4 | OOS net return, combined, 0.05% | >= 0 |
| A5 | OOS profit factor, combined, 0.05% | >= 1.00 |
| A6 | Wallet max drawdown, combined, 0.05% | < 35% |
| A7 | Profitable calendar years, combined, 0.05% | >= 60% |
| A8 | Profit factor, combined, full sample, 0.20% | >= 1.05 |
| E1 | Direction coverage: long-only and short-only both executed and reported with non-zero trades; no side disabled | both sides reported |
| E2 | Causality: prefix-invariance tests pass for structure, setup, geometry | all pass |
| E3 | No Turtle coupling: strategy code and signals never reference Turtle entry/exit | verified |

No criterion threshold may be changed after seeing results. A failure is reported
as a FAIL with the criterion named.

## 10. Reporting additions (descriptive only)

- Long-only, short-only and combined results; per-year and per-pair tables.
- **Trade geometry**: impulse size (ATR), pullback depth (ATR and %), pullback
  duration (bars), ATR-normalised distance from the structural origin, and
  continuation-trigger characteristics, plus per-trade MAE/MFE from freqtrade's
  `min_rate`/`max_rate`. Descriptive — not used to re-tune anything.
- **Complementarity preparation**: Turtle vs Pullback entry timestamps, trade
  overlap, simultaneous exposure, and return/drawdown correlation. Descriptive
  only; no combination is built and no optimisation is performed.

## 11. Expected failure modes

From `research/hypotheses/pullback_continuation.md` §8: pullback never confirms;
pullback becomes reversal; look-ahead via pivots; high correlation with Turtle;
parameter fragility. The pivot look-ahead risk is handled by §4.0's publication
delay and by the E2 causality tests.
