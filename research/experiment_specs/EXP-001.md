# EXP-001 — Experiment specification

| Field | Value |
|-------|-------|
| **Experiment ID** | EXP-001 |
| **Title** | Turtle raw baseline |
| **Strategy** | DonchianTurtleBaseline (rule-based, no ML) |
| **Branch** | `research/turtle-baseline` |
| **Config** | `user_data/configs/EXP-001.json` |
| **Status** | COMPLETED → FAIL |

## 1. Objective

Produce the reference price-action momentum baseline: a clean Donchian breakout
trend follower with fixed classic parameters, no ML, no regime classifier, no
router, and no optimisation. Measure whether the premise survives realistic costs
and out-of-sample data.

## 2. Hypothesis under test

> Price breaking out of its recent range marks the start of a directional move
> large enough, on average, to pay for the false breakouts around it.

Full statement: `research/hypotheses/turtle.md`.

## 3. Frozen implementation

| Element | Specification |
|---------|---------------|
| Timeframe | 4h |
| Entry channel | Donchian upper, period 20, shifted 1 bar |
| Entry condition | `close > dc_entry_upper` on the rising edge, ATR defined |
| Exit channel | Donchian lower, period 10, shifted 1 bar |
| Exit condition | `close < dc_exit_lower` |
| Stop | fixed `2 × ATR(20 at entry)`, plus −30% backstop |
| Sizing | `equity × 0.01 / stop_distance × price`, capped at equity |
| Direction | long only (spot) |
| Pyramiding | disabled |
| ROI | disabled |
| Max open trades | 5 |

## 4. Fixed parameters

`entry_period=20`, `exit_period=10`, `atr_period=20`, `atr_stop_multiple=2.0`,
`risk_per_trade=0.01`, `timeframe="4h"`.

None of these may be tuned in EXP-001. Parameter sensitivity is a separate,
pre-registered experiment.

## 5. Dataset

The pre-registered universe and periods in
`research/preregistration/experiment_protocol.md`:

- 10 Binance spot pairs, 4h
- full sample 2019-01-01 → 2026-01-01
- OOS holdout 2025-01-01 → 2026-01-01
- raw candles git-ignored, reproducible with `user_data/scripts/download_data.ps1`

## 6. Cost scenarios

| Scenario | Fee per side |
|----------|-------------|
| base | 0.05% |
| stress | 0.20% |

Slippage is not separately modelled by the framework; it is represented by the
stress fee scenario and flagged as a limitation.

## 7. Runs to perform

1. Full sample at base cost.
2. One OOS holdout run (once only for this version).
3. Full sample at stress cost.
4. One run per calendar year at base cost.

## 8. Success criteria

Charter criteria A1–A8, all of which must hold for a PASS. Reported
criterion-by-criterion regardless of outcome.

## 9. Out of scope

ML, regime detection, shorting, leverage, pyramiding, position re-entry,
portfolio routing, parameter optimisation, cross-sectional or residual momentum,
carry/basis signals.

## 10. Process note

This specification was authored together with the implementation on 2026-09-16 as
part of the project's foundation milestone. The strategy contains **no tunable
choice made after seeing results** — every parameter is the classic Turtle value
— so the out-of-sample run recorded in
`research/experiment_results/EXP-001.md` carries no selection bias. From EXP-002
onward, the specification and its parameters are frozen *before* the first run,
as required by the charter.
