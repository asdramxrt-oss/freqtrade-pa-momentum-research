# CELL-003 — Architecture / Next-Step Audit

## Goal
Based ONLY on verified repository evidence, determine what research work
should logically happen next.

Do not implement a new strategy.

Do not add ML, regime filters, routers, carry, momentum, or other components
unless repository evidence explicitly justifies further investigation.

Evaluate:
- current Turtle baseline
- complementary momentum research
- carry/basis work
- ML evidence
- regime evidence
- existing P3 results
- experimental gaps
- robustness gaps

The goal is to identify the smallest set of high-information next experiments.

When finished create:
.mece/cells/CELL-003/REPORT.md

The report must distinguish:
1. Established findings
2. Weak/uncertain findings
3. Unsupported assumptions
4. Missing experiments
5. Proposed next experiments
6. Why each experiment provides information
7. Risks of overfitting
